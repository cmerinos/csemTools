# csemTools 0.3.0

## New features
* Added `curvesCSEMcomp()` to compare two CSEM curves using polynomial regression, effect sizes (CSEM and variance ratios) with confidence intervals, and point‑wise significance regions with FDR correction. Plotting options are available via `ggplot2` and `patchwork`.

## Improvements
* Internal code now uses `patchwork` (suggested) for combined plots.
* Improved documentation and examples.
* Minor bug fixes in `checkAlpha`.
* Fix documentation
